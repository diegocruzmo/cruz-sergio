# Sergio Cruz — landing musical

Proyecto creado con React + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

Requiere Node.js 20.19 o superior; Node.js 22 es compatible.

## Personalizar contenidos

- Portada: agrega `public/images/portada-memorias-artesanales.jpg`.
- YouTube: reemplaza los valores `videoId` en `src/data/content.js`.
- Spotify: reemplaza cada `spotifyUrl` en `src/data/songs.js`.
- Contacto: cambia el correo de ejemplo en `src/data/content.js`.
